# 설정 결정 기록

전략과 백테스트에서 **우리가 정한 모든 설정값**과 그 근거. 보고서의 "방법론"과 "한계" 작성에 그대로 사용한다.

**근거 유형**
- **[논문]** 참고 논문의 방법 또는 값
- **[관행]** 실증 금융 연구에서 흔히 쓰는 방식
- **[데이터 확인]** 데이터를 직접 확인하고 정함 (수익률 성과는 보지 않음)
- **[팀 결정]** 논의로 정한 선택
- **[임의]** 뚜렷한 근거 없이 정한 값 → 민감도 분석 대상

참고 논문: [K24] Khelifa, Allier & Cucuringu (ICAIF 2024), [C23] Cartea, Cucuringu & Jin (ICAIF 2023)

## 1. 데이터 전처리
| 설정 | 값 | 근거 |
|---|---|---|
| 거래소 | EXCHCD ∈ {1, 2, 3} | [과제 지침] |
| 종목 식별자 | PERMNO | [과제 지침] |
| 수익률 | ADJ_PRC의 연속된 두 달 비율 − 1 | [과제 지침] ADJ_PRC 사용 |
| 가격 오류 제거 | ADJ_PRC > 100,000인 PERMNO 전체 제외 (34개) | [데이터 확인] 약 2조 달러 가격 등. 전체 기간을 보고 판단한 데이터 정리임을 명시 |
| 급등-반전 오류 | r_t > 300% 이고 (1+r_t)(1+r_{t+1}) − 1 < 50%면 두 달 결측 (2건) | [관행] Ince & Porter (2006) |
| NASDAQ 거래량 보정 | 2001-01 이전 ÷2.0, 2001-02~12 ÷1.8, 2002~03 ÷1.6 | [관행] Gao & Ritter (2010) |
| 최소 주가 필터 | **사용 안 함** | [데이터 확인] ADJ_PRC가 분할·배당으로 소급 조정되어(AAPL 2010-12 = 9.97) 과거 가격 필터에 미래 정보가 섞임 |
| 상장폐지 | 다음 달 가격 없음 → 마지막 관측 가격으로 평가 (그 달 0%), 가정 수익률 없음 | [팀 결정] 데이터 그대로 반영. 실제 상장폐지 손익은 데이터에 없어 반영 불가 (약 390건, 보유의 약 0.4%) |

## 2. 유니버스
| 설정 | 값 | 근거 |
|---|---|---|
| 이력 조건 | 추정 창 60개월 수익률이 모두 있는 종목 | [팀 결정] 상관행렬 계산에 필요. 상장 5년 미만 종목은 제외됨 |
| 유동성 조건 | 창 안 평균 거래량(보정 후) 상위 500종목 | [관행] + [팀 결정] 시가총액 정보가 없어 거래량을 대리변수로 사용. C23은 시가총액 상위 25% |
| 유니버스 크기 | 500 | [팀 결정] 관행과 추정 안정성의 균형 → 민감도: 200, 1,000 |

## 3. 추정 창과 가중치
| 설정 | 값 | 근거 |
|---|---|---|
| 방식 | 롤링 walk-forward, 매월 재추정 | [논문] K24 §4.1 (월별로 조정) |
| 추정 창 | 60개월 | [데이터 확인] 짧은 창(24·36개월)은 500종목 대비 관측치가 부족 |
| 시간 가중 | 반감기 18개월 지수가중 (유효 관측치 약 43, 최근 1개월 4.2%) | [논문] K24 §4.6 EWA + [데이터 확인] K와 시장 변동성의 연동성(0.68)이 비교한 방식 중 가장 높음. 수익률로 고르지 않음 → 민감도: 12, 24 |
| 적용 범위 | 시장 베타, 상관행렬, K, β, Σ*, 벤치마크 공분산 모두 같은 가중 | [팀 결정] 일관성 |
| 추정용 윈저라이징 | 월별 횡단면 상하위 1% | [관행] 추정에만 사용, 실현 수익률에는 미적용 |

## 4. 클러스터링
| 설정 | 값 | 근거 |
|---|---|---|
| 입력 | 시장 잔차 수익률의 상관행렬 (시장 = 유니버스 동일가중 평균) | [논문] C23 §2.2.1. SPY 대신 동일가중 평균은 주어진 데이터만 쓰기 위함 |
| 알고리즘 | SPONGE_sym | [논문] K24·C23 모두 최고 성능 |
| SPONGE τ+, τ− | 1, 1 | [임의] SigNet 기본값 |
| K 결정 | 매월 Marchenko–Pastur (λ₊ 초과 고유값 수), T에는 유효 관측치 사용 | [논문] C23 §2.3 + [데이터 확인] 누적 분산 90% 방식은 K가 39~44로 항상 상한에 걸림. 가중 데이터에 MP를 쓰는 것은 근사 |
| K 범위 | 3 ~ 20 | [팀 결정] 하한 3: K ≤ 2면 클러스터 간 분산 의미 없음. 상한 20: 유효 관측치 43 대비 추정 한계. 실제 K는 약 3~8 |
| 고정 K 비교 | **하지 않음** | [팀 결정] |
| 반복 횟수 R | 10회, 종목 최종 비중 평균 | [논문] K24 표 2 |
| k-means 초기화 | 반복당 3번 시도, 관성 최소 채택 | [임의] |
| 난수 시드 | 42 | [임의] 재현성용 → 민감도: 다른 시드 2개 |

## 5. 클러스터 안 비중 β
| 설정 | 값 | 근거 |
|---|---|---|
| 방식 | ② Gaussian kernel, ③ 역분산, ⑥ 주변부 가중 — 세 가지 모두 실행 | [팀 결정] |
| 공정한 비교 | 같은 반복에서 세 방식이 같은 클러스터 라벨 공유 | [팀 결정] β 효과만 분리 |
| Gaussian 폭 | σ² = 1.0 × 클러스터 안 평균 가중 거리² | [임의] K24는 교차검증. 결과를 보고 고르지 않기 위해 중간값 고정 → 민감도: 0.5, 2.0 |
| 주변부 점수 | β ∝ 1 − (클러스터 안 다른 종목과의 평균 상관) | [팀 결정] Pozzi, Di Matteo & Aste (2013)의 발상을 단순화 |

## 6. 클러스터 간 비중 α와 최종 비중
| 설정 | 값 | 근거 |
|---|---|---|
| 목적함수 | GMVP와 MSRP 모두 실행 | [팀 결정] K24는 목표수익률 제약 MVO |
| 포지션 | 롱온리 | [팀 결정] K24는 롱숏 |
| 기대수익 μ* | 가상 ETF의 과거 가중 평균 (MSRP에만 사용) | [팀 결정] K24의 미래 수익률 기반 η 설정은 미래 정보 누출이라 사용 안 함 |
| MSRP 예외 | 기대수익이 모두 0 이하이면 GMVP로 대체 (횟수 기록) | [팀 결정] |
| 최종 비중 | w_i = α_k × β_i | [논문] K24 §4.1 |
| 종목 상한 | 5%, 반복 평균 후 상한 포함 심플렉스로 투영 | [팀 결정] 쏠림 방지. 모든 전략에 동일 적용 |

## 9. 대표 전략 선택 규칙 (결과를 보기 전에 확정)
- **선택 구간:** 2005-02 ~ 2012-12
- **기준:** 거래비용 10bp에서 **Sharpe(RF 초과) 최대**인 클러스터 전략. 동률이면 MDD가 작은 쪽
- **검증 구간:** 2013-01 ~ 2020-12 성과는 선택에 쓰지 않고 그대로 보고
- **나머지 전략:** 모두 성과표에 함께 제시 (선택하지 않은 결과도 숨기지 않음)
- 구현: `metrics.select_main_strategy`

## 11. 보고서에 밝힐 한계
- 실제 상장폐지 손익(청산·인수 대금)을 반영하지 못함
- 시가총액이 없어 거래량(주식 수 기준, 분할 미조정)을 유동성 대리변수로 사용
- 가중 데이터에 Marchenko–Pastur를 쓰는 것은 이론의 근사
- 가격 오류 판정은 전체 기간 데이터를 보고 한 데이터 정리
- 반감기·창 길이·K 방식은 데이터를 확인하고 정했으나 수익률 성과는 보지 않음
- RF와 S&P 500은 외부 데이터 (전략 계산에는 사용하지 않음)
- 191개월 표본이라 전략 간 성과 차이의 통계적 유의성은 제한적

# 클러스터 내 자산배분(β) 방식 비교 — Cluster-driven Hierarchical Portfolio

금융공학개론 팀 프로젝트 — CRSP 미국 주식 월별 데이터(2000–2020)로 **매월 리밸런싱하는 롱온리 포트폴리오**를 백테스트했다.

> **연구 질문**: 상관구조로 종목을 클러스터로 묶은 뒤, **같은 클러스터 안에서는 어떤 종목에 비중을 줘야 하는가?**
>
> 기본 프레임워크는 Khelifa et al.(2024)의 구조를 그대로 두고, **클러스터 내 비중 β를 정하는 방식만 서로 다른 세 논문에서 가져와 교체**하며 성과를 비교했다.

## 1. 핵심 설계: β만 바꾸고 나머지는 고정

```
         [고정]                              [비교 대상]              [고정]
  유니버스 500종목                        클러스터 내 비중 β        클러스터 간 비중 α
       │                                        │                      │
       ▼                                        ▼                      ▼
 잔차 상관 → SPONGE_sym 클러스터링  →  ② Gaussian (중심)      →   K×K 공분산
   K = Marchenko–Pastur (3~20)          ③ 역분산 (저변동성)         GMVP / MSRP
   반복 10회                            ⑥ 주변부 (저상관)          종목 비중 w = α × β
```

**공정한 비교를 위한 장치**: 매월 같은 유니버스·같은 상관행렬·같은 K를 쓰고, **한 번의 클러스터링 결과(라벨)를 세 β 방식이 공유**한다. 따라서 성과 차이는 오직 β 방식에서 나온다. 구현: [`code/portfolio.py`](code/portfolio.py).

## 2. 비교한 세 가지 β 방식과 출처

| β 방식 | 원리 | 수식 | 출처 |
|---|---|---|---|
| **② Gaussian** (기준) | 클러스터 **중심에 가까운**(그룹을 대표하는) 종목에 집중 | β_i ∝ exp(−‖r_i − μ_k‖² / 2σ²) | **Khelifa, Allier & Cucuringu (2024)**, ICAIF '24, §4.2 |
| **③ 역분산 (IVP)** | **변동성이 낮은** 종목에 집중 | β_i ∝ 1 / σ_i² | **López de Prado (2016)**, *Building Diversified Portfolios that Outperform Out of Sample*, JPM 42(4) — HRP의 클러스터 내 배분 |
| **⑥ 주변부 (Periphery)** | 클러스터 안에서 **다른 종목과 덜 엮인** 종목에 집중 | β_i ∝ 1 − c̄_i (c̄_i = 클러스터 내 평균 상관) | **Pozzi, Di Matteo & Aste (2013)**, *Spread of risk across financial markets: better to invest in the peripheries*, Scientific Reports 3, 1665 |

세 방식은 **서로 정반대의 투자 철학**을 대표한다. Gaussian은 "클러스터를 대표하는 종목", 역분산은 "덜 흔들리는 종목", 주변부는 "클러스터 안에서도 분산 효과가 큰 종목"을 선호한다. 구현: [`code/allocation.py`](code/allocation.py).

## 3. 고정한 프레임워크 (Khelifa et al. 2024 + Cartea et al. 2023)

| 단계 | 방법 | 출처 |
|---|---|---|
| 시장 요인 제거 | 잔차 수익률 r_i − β_i·r_mkt | [C23] §2.2.1 |
| 클러스터 수 K | Marchenko–Pastur, 매월 동적 (3~20, 실제 3~8) | [C23] §2.3 |
| 클러스터링 | SPONGE_sym (부호 그래프) → k-means++, 10회 반복 후 비중 평균 | [K24] §3.4, §4.1 |
| 가상 ETF | r*_k = Σ β_i r_i | [K24] §4.1 |
| 클러스터 간 배분 α | K×K 공분산으로 GMVP 또는 MSRP (롱온리) | [K24] §4.1 / Markowitz (1952) |
| 최종 비중 | w_i = α_k × β_i, 종목당 5% 상한 | [K24] §4.1 |
| 추정 | 60개월 롤링 창, 반감기 18개월 지수가중 | [K24] §4.6 |

- [C23] Cartea, Cucuringu & Jin (2023), *Correlation Matrix Clustering for Statistical Arbitrage Portfolios*, ICAIF '23
- 단계별 출처는 [code/README.md](code/README.md), 모든 설정값과 근거는 [code/SETTINGS.md](code/SETTINGS.md)

## 4. 데이터와 백테스트

- **데이터**: 과제 제공 CRSP 월별 데이터(2000-01~2020-12, 12,573종목). **라이선스 문제로 저장소에 포함하지 않는다.**
- **전처리**: 거래소 필터 · 가격 오류 종목 34개 제외 · 급등 후 반전 오류 제거(Ince & Porter 2006) · NASDAQ 거래량 보정(Gao & Ritter 2010) · 상장폐지는 마지막 관측 가격으로 평가(가정 수익률 없음)
  ※ ADJ_PRC가 분할·배당으로 소급 조정된 가격이라 최소 주가($5) 필터는 미래 정보가 섞여 사용하지 않았다.
- **유니버스**: 매월 60개월 수익률이 완비된 종목 중 평균 거래량 상위 500
- **평가**: rolling walk-forward, **2005-02 ~ 2020-12 (191개월)**, 거래비용 0 / 1 / 10bp
- **평가용 외부 데이터**(전략 계산에는 미사용): Ken French 무위험 수익률, S&P 500 총수익지수(^SP500TR)

## 6. 발견

1. **역분산(IVP)이 세 방식 중 가장 우수했다.** 두 하위 구간과 전체 기간, GMVP·MSRP 모두에서 Sharpe가 가장 높았고 변동성·MDD·회전율은 가장 낮았다. 구간과 최적화 방식을 바꿔도 순위가 유지되어 **비교적 견고한 결과**다.
2. **원 논문의 Gaussian 방식은 중간이었다.** 클러스터 중심에 집중하는 방식은 위험을 직접 보지 않기 때문에, 변동성이 큰 종목도 "중심에 가까우면" 큰 비중을 받는다. 그 결과 베타가 1에 가깝고(0.99) MDD가 −55%까지 커졌다.
3. **주변부 방식은 기대와 반대로 가장 나빴다.** 클러스터 안에서 상관이 낮은 종목은 분산 효과가 클 것으로 기대했지만, 실제로는 **소형·고변동 종목으로 기울어** 변동성 17~20%, 베타 1.08~1.17로 가장 공격적인 포트폴리오가 됐다. Pozzi et al.(2013)의 결과가 월별·대형주 유니버스에서는 재현되지 않았다.
4. **β 방식이 시장 노출을 좌우한다.** 같은 클러스터, 같은 α 규칙인데도 베타가 0.84(역분산) ~ 1.17(주변부)까지 벌어졌다. 클러스터 내 배분은 단순한 세부사항이 아니라 **포트폴리오 성격을 결정하는 선택**이다.
5. **회전율 차이도 컸다.** 역분산 31% < Gaussian 40% < 주변부 44%(월). 거래비용이 커질수록 역분산의 상대적 우위가 커진다.
6. **시장을 통계적으로 이기지는 못했다.** 최고 성과인 역분산 GMVP의 Sharpe 0.64는 S&P 500(0.63)과 사실상 동일하다(알파 연 0.6%, t = 0.57). 191개월 표본에서 Sharpe의 표준오차는 연 0.25로, 이 정도 차이는 우연과 구분되지 않는다. 다만 **동일가중은 시장보다 유의하게 나빴다**(z = −2.17).
7. **클러스터링이 위험을 줄인다는 가설은 지지되지 않았다.** 클러스터링 없는 GMVP가 변동성 12.0%, MDD −42.3%로 모든 클러스터 전략보다 안정적이었다. 가상 ETF는 수십~수백 종목 바스켓이라 **각각의 시장 베타가 1에 가깝고**, 그 사이에서 최소분산을 풀어도 시장 노출을 줄이기 어렵기 때문으로 보인다. 역분산이 상대적으로 선전한 것도 클러스터 내부에서 저변동 종목으로 기울어 이 한계를 일부 보완했기 때문으로 해석된다.

## 7. 한계

- 데이터에 상장폐지 수익률이 없어 실제 상장폐지 손익을 반영하지 못함
- 시가총액이 없어 거래량(주식 수 기준)을 유동성 대리변수로 사용
- 주변부 방식은 원 논문의 네트워크 필터링(MST·PMFG) 대신 **클러스터 내 평균 상관**으로 단순화함
- 지수가중 데이터에 Marchenko–Pastur를 적용한 것은 이론의 근사
- 평가 기간이 2005년부터라 닷컴 붕괴(2000–2002)는 포함되지 않음
- 191개월 표본으로는 전략 간 차이의 통계적 판별력이 낮음

## 8. 저장소 구성

```
code/       전략·백테스트 코드 (모든 줄에 주석)
  allocation.py   ★ 비교 대상인 β 3종 (gaussian / ivp / periphery)
  portfolio.py    ★ 세 β가 같은 클러스터를 공유하도록 구성
  config.py       모든 설정값
  data.py         로드·전처리·유니버스·시간 가중
  clustering.py   K 결정, SPONGE_sym, k-means++
  optimization.py 공분산, Ledoit–Wolf, GMVP, MSRP
  backtest.py     월별 walk-forward
  metrics.py      성과지표, 대표 전략 선택 규칙
  benchmarks.py   RF·S&P 500 총수익지수 준비
  report.py       성과표·그래프 생성
  main.py         실행 진입점
  README.md       파이프라인과 단계별 출처
  SETTINGS.md     모든 설정값과 근거, 민감도 계획, 한계
output/     결과물 (성과표, 월별 수익률, 회전율, 진단, 클러스터 구성, 그래프)
data/       입력 데이터 (저장소에 포함하지 않음)
```

## 9. 실행 방법

```bash
pip install numpy pandas matplotlib yfinance
cd code
python benchmarks.py   # 최초 1회: RF, S&P 500 총수익지수 준비
python main.py         # 백테스트 (약 1시간) → output/
python report.py       # 저장된 결과로 성과표·그래프만 재생성
```
β 방식은 `config.py`의 `intra_methods`에서 선택한다.

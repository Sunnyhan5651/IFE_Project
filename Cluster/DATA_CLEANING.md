# 데이터 정제 과정

## 원본 데이터

- **출처**: CRSP 월간 미국 주식 데이터
- **거래소**: NYSE, AMEX, NASDAQ
- **기간**: 2000–2020

---

## 정제 단계

### Step 1. 이상 주가 종목 제거

```python
bad_permno = df.loc[df["ADJ_PRC"] > 1e6, "PERMNO"].unique()
```

수정 주가(ADJ_PRC)가 **$1,000,000 초과**인 종목을 전체 기간에 걸쳐 제거합니다.

- 발생 원인: 주식분할 미반영, 데이터 입력 오류 등
- 해당 PERMNO가 한 번이라도 이 조건에 해당하면 전체 기간에서 제외

---

### Step 2. 거래소 필터

```python
df["EXCHCD"].isin([1, 2, 3])
```

| EXCHCD | 거래소 |
|--------|--------|
| 1 | NYSE (뉴욕증권거래소) |
| 2 | AMEX (아메리칸증권거래소) |
| 3 | NASDAQ |

OTC 및 기타 소규모 거래소 종목은 유동성과 데이터 신뢰도 문제로 제외합니다.

---

### Step 3. 수익률 윈저라이징 (Winsorizing)

```python
ret_wins = ret_wide.clip(
    lower=ret_wide.quantile(0.01, axis=1),
    upper=ret_wide.quantile(0.99, axis=1),
    axis=0,
)
```

매월 수익률 분포의 **하위 1%, 상위 1%를 해당 경계값으로 대체**합니다.

- 발생 원인: 상장폐지 직전 급락, 단기 급등, 데이터 오류 등
- 목적: 극단적 수익률이 상관행렬 추정을 왜곡하지 않도록 방지
- 방식: 제거가 아닌 경계값으로 대체(clip)하여 데이터 손실 최소화

---

## 매월 유니버스 필터 (백테스트 루프 내)

정제된 데이터에서 매 리밸런싱 시점마다 아래 조건을 추가로 적용합니다.

| 조건 | 기준 | 목적 |
|------|------|------|
| 최소 관측 기간 | 60개월 이상 | 안정적인 상관행렬 추정 |
| 최소 주가 | $5 이상 | 페니스톡 제외 |
| 최소 거래량 | 하위 20% 제외 | 유동성 낮은 종목 제외 |

세 조건을 모두 충족한 종목만 해당 월의 **Asset Universe**로 선정됩니다.

## 정제 흐름 요약

```
원본 CRSP 데이터
    ↓  ADJ_PRC > $1,000,000 종목 전체 제거

    ↓  월간 수익률 상하위 1% 윈저라이징
정제 완료 데이터
    ↓  (매월) 관측 기간 60개월 미만 제외

    ↓  (매월) 거래량 하위 20% 제외
월별 Asset Universe
```
